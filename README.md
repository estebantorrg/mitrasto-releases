# MiTrasto — versiones publicadas

Rutas, estaciones y buses en vivo de TransMilenio y el SITP: **[mitrasto.app](https://mitrasto.app)**.

Este repositorio solo publica:

- **La app para Android**, en [Releases](https://github.com/estebantorrg/mitrasto-releases/releases/latest). La forma fácil de instalarla, con los pasos que pide Android, es **[mitrasto.app/app](https://mitrasto.app/app/)**. La app avisa sola cuando hay una versión nueva.
- **Los datos del catálogo** que usa el servidor (la pre-versión `catalog-data`).
- **Los anuncios de MiTrasto**, publicados como issues con la etiqueta `anuncio`.
